# 人生規劃儀表板（Life Planning Dashboard）

一套以瀏覽器執行的開源人生財務規劃工具，用於模擬收入、支出、資產、負債、投資、不動產、保單與保障缺口，並將結果投影至 100 歲。

> 本專案目前為原型版本，主要用途為財務教育、情境模擬與初步規劃，不構成保險、投資、稅務、法律或其他專業建議。

## 專案目標

人生財務規劃往往分散在不同試算表與保險規劃文件中。本專案希望以單一儀表板整合：

- 人生階段收入與支出
- 現金、投資與不動產
- 固定支出與負債
- 保單與保障需求
- 通膨、報酬率與資產耗盡風險
- 保障缺口與百歲資產投影

所有資料預設在使用者瀏覽器中處理，並可匯出為 JSON 備份。

## 主要功能

### 財務基礎設定

- 現在年齡與試算基準日
- 主業與副業收入
- 單利或複利成長模式
- 婚姻狀態、受扶養人與扶養期間
- 通膨率、投資報酬率與現金利率
- 人生階段收入與支出調整

### 六大保障需求

- 身故保障
- 意外失能
- 醫療保障
- 癌症保障
- 重大傷病
- 長期照顧

### 資產與負債

- 現金與可投資資產
- 一次投入與定期定額
- 不動產估值
- 其他持有資產
- 固定支出
- 房貸、車貸及其他負債
- 投資型保單帳戶

### 視覺化輸出

- 各年齡保障缺口
- 現金、投資與不動產資產線
- 資產耗盡年齡
- 100 歲資產估值
- 年齡別財務比率
- 最大保障缺口年齡

### 資料管理

- 本機存檔
- JSON 匯入與匯出
- 復原與重做
- 載入範例資料

## 快速開始

本專案為純前端 HTML、CSS 與 JavaScript 應用程式，不需要後端服務。

### 方法一：直接開啟

下載專案後，以瀏覽器開啟 `index.html`。

### 方法二：使用本機伺服器

Python：

```bash
python -m http.server 8000
```

然後開啟：

```text
http://localhost:8000
```

Node.js：

```bash
npx serve .
```

## 計算與模型限制

目前計算屬於情境模擬，而非精算、稅務申報或投資顧問模型。結果可能受到以下因素影響：

- 稅制、保險制度與法規變動
- 報酬率、通膨率及收入成長率假設
- 未納入的費用、稅負、風險事件與市場波動
- 保單條款差異、等待期、除外責任與給付限制
- 使用者輸入錯誤或資料不完整

詳細內容請參閱 [DISCLAIMER.md](DISCLAIMER.md)。

## 隱私

本專案目前為瀏覽器端工具。使用者應避免輸入可識別個人的敏感資料，並自行妥善保管匯出的 JSON 檔案。

在部署或修改版本時，維護者應明確揭露是否新增：

- 遠端資料傳輸
- 分析追蹤
- 第三方服務
- 雲端儲存
- 使用者帳戶系統
