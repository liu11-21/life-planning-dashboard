# 人生規劃模型涵蓋範圍檢查

檢查日期：2026-10-21。依目前 `app.js` 的資料欄位、收支流向及函式逐項核對；這是實作涵蓋範圍盤點，沒有替使用者假設退休資格、稅務資格或保單條款。

## 已納入

- 主副業收入、成長率與有起訖日的人生階段；階段重疊時取最後一個符合者。
- 生活費通膨、固定支出、資產持有成本、房屋／車輛稅的簡化估算。
- 簡化所得稅、貸款月付款及到期清償、年度保費。
- 一次與定期投資、固定報酬、到期收回及指定年齡的投資再平衡。
- 期末現金、投資餘額、持有資產估值、還款後負債與淨資產。
- 六類保障的需求、給付約當換算、一次金缺口與財務比率。

公式與時點詳見 [計算假設](CALCULATION_ASSUMPTIONS.md)。

## 優先補足的項目

| 優先度 | 項目 | 程式證據 | 對結果的影響 | 目前可採取的方式／後續實作 |
|---|---|---|---|---|
| 高 | 退休後收入與退休金 | `financialAtAge` 只依基礎收入起訖日或人生階段計算；沒有勞保、勞退、年金規則 | 基礎收入結束日空白且無階段覆蓋時，收入可延續至 100 歲；可能高估退休資產 | 設定基礎收入結束日，另建退休收入階段；未來加入退休金來源、開始日與給付方式 |
| 高 | 購屋、購車、出售及貸款撥款 | `assetValueAtDate` 僅計持有估值；`projectPlan` 現金恆等式沒有買賣價款或貸款撥款項 | 未來資產可能直接出現在淨資產中，卻未扣購買款；資產結束持有後也不會收回出售款。貸款會產生負債與還款，沒有入帳借款本金 | 未來增加交易事件，連動價款、貸款、稅費及資產；目前需另外核對資金來源，持有成本不能取代交易款 |
| 高 | 保單繳費期間 | `activePoliciesAt` 由保障起訖年齡篩選；`premiumAtAge` 的平準保費沒有獨立繳費期限 | 繳費 20 年、保障終身的契約若填平準保費，可能整段保障期都扣保費 | 現有「非平準」分段保費可僅填實際繳費年齡，未匹配的年齡保費為 0；未來獨立繳費與保障日期 |
| 高 | 理賠條件及主附約連動 | `projectPlan` 將同類給付逐筆相加；`activePoliciesAt` 只檢查保單自己的年齡 | 互斥給付可能被同時加總；附約不會自動隨主約結束而停止。等待期、除外、豁免與理賠次數上限未判斷 | 核對實際可同時理賠的保障；未來加入給付事件與主附約有效性規則 |
| 高 | 既有投資本金與新投入的區分 | `projectPlan` 投資餘額由 0 起算；`investmentForYear` 會把第一年一次投入從現金扣除，即使起始日早於基準日 | 輸入的「目前可投資資產」必須與一次投入的資金來源對得上；模型不能直接重建歷史投資帳戶 | 未來分開期初現金、既有投資市值、成本與新投入；目前用年度收支明細核對第一年現金 |
| 高 | 投資型保單的總繳款 | `projectPlan` 分別扣 `premium` 與 `policyInvestmentContribution` | 若保費已包含投資款，兩個欄位都填總繳款會重複計入支出 | 依契約拆開保費與投資投入；未來提供總繳款拆分模式與重複提醒 |
| 中 | 年中收入及支出變動 | `financialAtAge`、`annualExpenseAtDate`、`fixedExpenseAtDate` 取年度基準日，再算全年金額 | 年中開始或結束的工作、生活費、持有成本可能整年計入或漏掉；投資、貸款的月度時點較細 | 未來統一逐月現金流，明確處理部分年度 |
| 中 | 家庭與人生事件 | 目前欄位有扶養人數、扶養年數、固定支出與人生階段，沒有婚育、教育、照顧事件引擎 | 子女教育、父母照顧、搬家、失業與疾病後收入減少不會自動發生 | 可手動建收入階段、固定支出；未來加入事件日期、一次費用與持續費用 |
| 中 | 所得稅與薪資扣款 | `estimateIncomeTax` 使用固定 115 年級距及目前婚姻、扶養人數；沒有投資所得稅或勞健保扣款項 | 未來稅制、配偶收入、扶養資格、列舉扣除、勞健保／自提退休金及海外／股利稅可能未反映 | 支出可補入已知扣款；未來新增稅務資格期間與各類所得。扶養需求年數不等於報稅扶養資格，不能直接相互替代 |
| 中 | 波動、費用與匯率 | `investmentForYear` 為固定年化報酬，沒有費率、投資稅費或外幣欄位 | 平均報酬相同時仍可能有不同退休結果；費用與稅會降低可用資產 | 目前可保守調整淨報酬率做比較；未來加入費用與多情境路徑 |
| 中 | 緊急準備金與退休提領 | 儀表板有現金可支應月數，但 `projectPlan` 不會因目標水位自動停止投資、借款或變現 | 現金負值代表缺口，沒有自動籌資；淨資產正值不保證可支付當期帳單 | 先查看首次現金缺口與年度明細；未來加入準備金目標、資產可變現性及提領順序 |
| 中 | 醫療通膨、長壽、遺贈 | `needsAtAge` 使用一般通膨；投影到 100 歲；沒有醫療獨立通膨、死亡機率或遺贈稅 | 特定風險準備金與跨代資產規劃可能不足 | 未來加入分項通膨、可選期限及遺贈情境 |

## 必須理解的顯示口徑

1. 每列是該年齡基準日起一年的收支，100 歲列也包含往後一年；不是到生日當天即停止。
2. 現金、投資、負債使用年度結束狀態；持有資產使用年度基準日估值，仍有時點差異。
3. 第一年現金不計存款利息，是現行明示假設；後續只對正現金計息。負現金不會產生未設定的借款利息。
4. 日額乘 180 日、月額乘 12 及長照年數、每次給付乘 3，只是比較用換算，不是確定理賠收入。疾病、失能或身故不會在現金流中自動發生。
5. 金額是名目新臺幣；沒有換算為今日購買力。非流動資產不等於當期可用現金。
6. 「年收支結餘」為收入減生活與持有支出、稅、貸款還款和保費，尚未扣新投資投入，也未加回清算及現金利息。年度明細才是完整現金流。
